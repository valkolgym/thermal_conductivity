# Теплопровідність металу: цвяхи на воску

![HTML5](https://shields.io)
![CSS3](https://shields.io)
![JavaScript](https://shields.io)

Інтерактивна вебсимуляція фізичного досліду, яка демонструє явище теплопровідності твердих тіл на прикладі нагрівання металевого стержня.

🔗 **[Запустити симуляцію онлайн (Live Demo)](https://valkolgym.github.io/thermal_conductivity/)**

## 📖 Опис досліду

До горизонтально закріпленого металевого стержня за допомогою воску прикріплені цвяхи на різній відстані від краю. Правий кінець стержня нагрівається пальником. 

Тепло поширюється вздовж металевого стержня від нагрітого кінця до холодного. У міру прогрівання металу віск плавиться, і цвяхи по черзі відпадають — починаючи від найближчого до полум'я і закінчуючи найвіддаленішим.

## 🔬 Обладнання у симуляції
* **Штатив** — для фіксації експериментальної установки.
* **Металевий стержень** — провідник тепла.
* **Пальник** — джерело теплової енергії.
* **Цвяхи та віск** — індикатори поширення тепла вздовж стержня.

## 🎮 Можливості та керування

Симуляція містить інтерактивну панель керування для проведення та аналізу експерименту:
* **▶ Почати нагрівання** — запуск пальника та початок процесу передачі тепла.
* **↺ Спочатку** — скидання симуляції до початкового стану (повернення цвяхів на місце, обнулення таймера).
* **Швидкість (×1)** — регулювання швидкості перебігу часу в експерименті.
* **Таймер (0 с)** — відлік часу від початку нагрівання для фіксації моменту відпадання кожного цвяха.
* **Хід досліду** — текстовий журнал подій, який покроково описує поточний стан експерименту.

## 🛠️ Технології
* **HTML5** — структура вебсторінки та графічних елементів досліду.
* **CSS3** — стилізація інтерфейсу, анімації нагрівання та адаптивність.
* **JavaScript (Vanilla JS)** — фізична логіка поширення тепла, керування таймером та інтерактивність.
